Task25-Logistic Regression Classification

Project Overview

This project demonstrates the implementation of a **Logistic Regression Classification model** using Python and Scikit-learn.

The **Breast Cancer Wisconsin Dataset** is used to classify breast cancer cases into two categories: **malignant** and **benign**.

The project covers data preprocessing, feature scaling, model training, prediction, probability estimation, and model evaluation.


## Objectives

- Load and explore a classification dataset.
- Check and preprocess the data.
- Split the dataset into training and testing sets.
- Standardize numerical features.
- Build a Logistic Regression classification model.
- Generate class predictions.
- Calculate prediction probabilities.
- Evaluate model performance using:
  - Accuracy
  - Confusion Matrix
  - Classification Report


##  Dataset

The project uses the **Breast Cancer Wisconsin Dataset** available through Scikit-learn.

The dataset contains numerical measurements computed from breast cancer cell images.

### Target Classes

| Target | Class |
|---|---|
| 0 | Malignant |
| 1 | Benign |

The dataset contains **569 samples** and **30 numerical features**.

##Conclusion
The Logistic Regression model was successfully built for binary classification using the Breast Cancer Wisconsin dataset. The data was preprocessed and numerical features were standardized before training. The model was used to make predictions and predict probabilities. Its performance was evaluated using accuracy, confusion matrix, and classification report.
